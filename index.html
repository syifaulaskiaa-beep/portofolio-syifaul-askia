01 — Tentang

Dari rancangan di atas kertas sampai kode yang jalan

Saya senang menuntaskan ide jadi sesuatu yang bisa langsung diklik dan dicoba — dari aplikasi produktivitas kecil sampai dua situs e-commerce lengkap dengan keranjang belanja dan checkout, semuanya dibangun dari nol dengan HTML, CSS, dan JavaScript murni.

Saat ini saya sedang memperdalam pengembangan front-end, logika interaktif JavaScript (keranjang, filter, form multi-langkah), dan integrasi dengan API publik untuk data real-time seperti cuaca.

04 — Aktivitas

Proses pengembangan proyek

  • Pengembangan

    Membangun 5 Aplikasi Web

    Merancang dan membangun To-Do List, Pasarku, Kalkulator BMI, Wastra Atelier, dan Weather App dari nol dengan HTML, CSS, dan JavaScript.

  • Version Control

    Upload Proyek ke GitHub

    Membuat repository, meng-upload kode, dan mengaktifkan GitHub Pages agar proyek bisa diakses lewat live demo.

  • Debugging

    Memperbaiki Bug Tampilan

    Menelusuri dan memperbaiki bug modal produk serta konflik atribut hidden pada situs Pasarku dan Wastra Atelier.

  • Integrasi API

    Menghubungkan Data Cuaca Real-time

    Mengintegrasikan Weather App dengan Open-Meteo API untuk menampilkan data cuaca, prakiraan per jam, dan 7 hari.
